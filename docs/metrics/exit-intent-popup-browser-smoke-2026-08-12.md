# Exit-intent newsletter popup browser smoke

**Checked:** 12 August 2026  
**URL:** https://www.zerotovpn.com/  
**Surface:** Codex in-app browser, production HTML/client runtime

## Result

The exit-intent trigger opened a visible dialog titled **“Get VPN Reviews & Security Tips 🔒”** after the pointer moved to the top edge of the viewport. The dialog contains:

- a first-party newsletter description;
- an email field;
- explicit email consent;
- a subscribe action;
- privacy/unsubscribe copy;
- dismiss and “Don’t show this again” actions.

The dialog contained **zero anchor elements** and therefore no affiliate destination, provider CTA, coupon, discount, incentive or deal link. No form was submitted during this smoke test.

This confirms the popup remains available for email collection while staying separate from affiliate promotion. The automated editorial guard remains the release authority for preventing commercial copy from being added later.
